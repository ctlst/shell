# Ownership and third-party dependencies

This core source snapshot contains CTLST-authored source, configuration,
documentation and project-created artwork. Original CTLST work is Apache-2.0;
preserve LICENSE and NOTICE. CTLST did not create Sway, GTK, Waybar, libinput,
Mako, Foot or the other system dependencies named in dependencies/.

Those applications/libraries/fonts are installed separately and retain their
upstream identities and licenses. No upstream keyboard/gesture fork, font
binary, shared library, firmware or device image is bundled in this snapshot.
Optional upstream-derived work in the private device/extraction repositories
is deliberately excluded rather than presented as original CTLST code.

The wallpapers and original SVG icons are project-created/generated artwork.
They are offered under Apache-2.0 to the extent rights exist and are held by
Vladimir Kovalchuk. This does not grant rights to third-party names or marks.
Historical screenshots are not included in this source snapshot.

See packages/CORE-CONTENTS.md for the core/companion/device boundary. Report
unclear origin or missing notices before redistributing a questionable file.
